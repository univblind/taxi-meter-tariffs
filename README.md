# 택시 미터기 요금표 데이터

택시 미터기 앱이 사용하는 전세계 국가·지역별 택시 요금표입니다.
앱은 시작할 때 아래 주소의 파일을 확인해, 내장된 요금표보다 새 버전이면 내려받아 사용합니다.

- 파일 주소: https://univblind.github.io/taxi-meter-tariffs/tariffs.json

## 요금을 고치는 방법

1. `tariffs.json` 에서 해당 지역 항목을 찾아 숫자를 고칩니다.
2. 파일 맨 위의 `"version"` 을 **1 올리고** `"updated"` 날짜를 오늘로 바꿉니다.
   버전이 올라가지 않으면 앱이 새 요금표로 인식하지 않습니다.
3. 저장(커밋)하면 1~2분 뒤 앱에 반영됩니다. 앱을 다시 켜거나 설정의 "지금 업데이트 확인"을 누르면 됩니다.

형식이 깨진 파일은 앱이 무시하고 기존 요금표를 계속 사용하므로, 실수로 앱이 멈추지는 않습니다.

## 항목 설명

| 항목 | 뜻 |
| --- | --- |
| `baseFare`, `baseDistanceM` | 기본요금과 기본요금에 포함된 거리(m) |
| `distanceTiers` | 거리요금. `unitM` 미터마다 `fare` 만큼 오릅니다. `uptoM` 은 그 단가가 적용되는 누적 거리 한도이고 마지막 구간은 `null` 입니다 |
| `timeUnitSec`, `timeFare`, `slowSpeedKmh` | 속도가 `slowSpeedKmh` 이하일 때 `timeUnitSec` 초마다 `timeFare` 만큼 오릅니다 |
| `surcharges` | 시간대·요일 할증. `percent` 는 비율, `flat` 은 고정 추가금, `baseFare` 는 그 시간대의 기본요금 |
| `extras` | 탈 때 한 번 붙는 고정 추가금 |
| `minFare` | 최소 요금 |
| `lat`, `lng`, `radiusKm` | 위치 자동 감지에 쓰는 지역 중심 좌표와 반경 |

km당 요금을 `unitM` 으로 바꾸려면 `단위요금 ÷ km당요금 × 1000` 으로 계산합니다.
예를 들어 km당 2.80유로를 0.10유로 단위로 올리면 `0.1 ÷ 2.8 × 1000 = 35.71` 입니다.

## 주의

이 요금표는 공개 자료를 바탕으로 정리한 참고용이며 실제 요금과 다를 수 있습니다.
